# ***АИС производства автомобильных газотурбинных двигателей***

Автоматизированная информационная система для автоматизации бизнес-процессов предприятия «Производство автомобильных газотурбинных двигателей».

## **Что умеет система**

- Ведёт учёт сотрудников, двигателей и комплектующих
- Учитывает поставщиков и заказы
- Контролирует качество выпускаемых двигателей по результатам испытаний
- Хранит данные об оборудовании цехов и складских помещениях
- Формирует отчётность по производству

## **Структура проекта**

- *frontend* — клиентская часть (интерфейс)
- *backend* — серверная часть, бизнес-логика
- *database* — схема базы данных
- *docs* — документация проекта

## **Установка**

Склонируйте репозиторий с GitHub и перейдите в папку проекта.

## **Использование**

После установки запустите проект и откройте интерфейс в браузере. Система позволяет вносить данные о сотрудниках, двигателях, заказах и комплектующих, а также формировать отчёты по производству.
